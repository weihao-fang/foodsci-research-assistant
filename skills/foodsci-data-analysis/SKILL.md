# FoodSci 数据分析与图表

本入口属于FoodSci六入口套件，依赖同级同版本 `foodsci-research-assistant` 总文件夹，不能单独取走。只安装总文件夹也可完成所有任务。

读取[数据分析](../foodsci-research-assistant/references/data-analysis.md)，按真实数据、设计及可用工具完成分析或待运行计划。随包固定脚本仍只处理RAW/消化描述汇总，其它计算必须实际实施才报告。图表、结果与输入记录保留定位。

混料/时间/批次结构、菌群组成与RNA计数、距离分析或预测验证读取[方法决策](../foodsci-research-assistant/references/scientific-methods.md)。分析依赖专业注释时，再用[资源手册](../foodsci-research-assistant/references/food-bio-resources.md)核对来源、ID映射和版本，不把数据库预测写成实测功能。

按用户本次目标读取相关模块并完成实际交付，共享来源/主张/实验/数据/图ID。没有独立调度接口时直接应用包内规则，不声称有未运行的后台代理；只要局部任务就完成该部分。不要加载全部方法、补造来源/数据或上传私有资料到无关服务。
