# 食品生产与放大：实验设计、分析与审稿修订

用于单元操作、实验室到中试/生产的放大研究，以及质量、产能、资源消耗的证据审查。无专用数值脚本；不自动设置工业工艺参数、放行限值、CCP 或作出法规认证。

## 先定义目标与边界

- 明确产品、原料、目标人群/用途及实际市场范围；给出单元操作流程图、设备尺度、批式/半连续/连续方式、工艺路线和采样位置。
- 区分实验室可行性、中试可重复性、产线稳定性、商业成本、质量放行与食品安全验证；每种结论需要不同的观测范围，不能互相替代。
- 提供原料/生产批次、设备和产线、运行日/班次、关键物料流、投料/成品/返工/废弃、启停与清洗、故障/停机、包装和贮藏记录，以及测量仪器的校准依据。
- 明确主要终点与预定比较：例如合格品得率、物性、实际吞吐、单位合格品能耗/用水、或特定控制措施效果；不把所有结果压成一个无定义的“生产效率”。

## 设计、对照与放大取舍

| 研究问题 | 比较与需要记录的条件 | 不应直接外推的事项 |
|---|---|---|
| 新工艺相对现有工艺 | 适用基准工艺，匹配或显式调整原料、产品规格与检测方法 | 规格、水分或合格率不同会改变产能/能耗的分母 |
| 单元操作优化 | 因素、允许范围、设备几何与负荷、温度/流量/压力等实测轨迹 | 设备设定值不等于每份食品实际经历的过程 |
| 从小试放大 | 说明保持或改变的混合、传热/传质、剪切、停留时间等尺度依据 | 同转速、同处理时间或同比放大体积不能自动保证等效 |
| 产线连续运行 | 覆盖启动、稳定、转换和异常阶段，定义合格产品与时间窗口 | 最佳短时速率不等于长期产能；剔除停机后需明确分母 |
| 质量/安全控制 | 先识别实际危害与产品质量目标，再定义对应证据 | 感官合格、单次成品检测或高得率不证明全部食品安全 |

- 处理在什么层级独立分配，决定其独立单位：原料批次、独立生产运行、产线或时段需区分。同批大量成品、连续传感器读数与多点进样通常是单位内观测。
- 不同产线各采用一种工艺时，产线差异可能与工艺混杂；按可行性使用交叉、区组或其他可识别比较，若无法分离就限定结论。
- 连续过程保留时间相关、漂移、滞后和残留效应；按预先定义的稳定窗口及适当独立运行分析，不用任意分钟切片制造 n。
- 样本量与跨批/跨日覆盖依据主要终点、预期变异及外推范围规划；不固定“成功三批”等同验证完成。确认条件应与选优数据区分。

## 物料、能源与成本的分析口径

1. **物料边界**：声明计算针对一个单元、整线还是整个工厂，以及批次或时间段。总质量核对输入、输出、积累和未解释损失；有反应时成分衡算还须计生成/消耗，不能把成分变化冒充总质量损失。
2. **基准一致**：水、蒸汽冷凝、挥发、返工/回流、联产品和废弃需按边界列示；湿基与干基、原料投入与已消耗组分、总产品与合格品分开。缺少流量/含水率时先列待测量项，不补造“闭合率”。
3. **能源与用水**：定义购入电/燃料、设备端有效热量、回收热及边界损失；避免把热回收和能源投入重复计入。说明公用工程、制冷、清洗、启动/空载是否纳入，以及每 kg 原料或合格产品等分母。
4. **产能与得率**：区分瞬时流率、稳定期平均与含启停/清洗/换线/停机的时间平均；给出实际运行时长、合格率和报废/返工。设备铭牌能力与推算排班需标为假设。
5. **经济与环境评价**：成本提供币种/日期、原料和公用工程价格、设备利用率、人工/折旧等实际范围；未测项做透明情景分析，不写成实测工业节约。生命周期/碳结论需另定义功能单位、系统边界及数据来源。

分析先展示各独立批次/运行与不合格数据，再比较效应及区间；有配对、区组或连续时间结构时据此建模。不得用稳定均值掩盖运行漂移或把未检测产品都计入合格产出。

## 质量放行与食品安全分开核查

- 放行规格需提供项目、方法、抽样和判定依据；研发目标、企业规格、法规限值不可混称。依据未核对时标“待核验”，不生成通用菌落/温度/添加剂限值。
- HACCP 从具体原料、过程、贮藏、分销和预期用途的生物/化学/物理危害分析开始；按发生可能性与后果辨认需要控制的危害，再确定措施和 CCP。不能把每个质量指标或每道工序默认列为 CCP。
- 区分基础卫生/前提方案、控制措施有效性的验证依据、运行监测、偏差纠正与持续核查；单份 HACCP 表或实验室杀菌现象不等于现场食品安全体系已获证明。
- 产品、设备、负荷或包装改变时核查原证据是否适用；科学设计指导不能代替现场具备相应职责人员的确认，也不声称取得认证或现行法域合规。

## 审稿修订：最小证据与降级路径

| 主张或可定位问题 | 最小可验收修改 | 证据不足时的结论路径 |
|---|---|---|
| 小试数据写成“已实现工业生产” | 列实际尺度、运行覆盖、独立批次及与工业条件的差异 | 限为小试可行性或中试条件下表现 |
| “节能/低成本”，分母或边界变化 | 统一功能单位并给原始投入、合格产出、边界和假设 | 改为特定边界的估计/情景结果，不给实测节约结论 |
| 同一次连续运行数千点写成 n 数千 | 按独立运行与时间相关重报分析 | 只报告该次运行轨迹与稳定性，推断标探索性 |
| “安全且可放行”仅凭质量或少量成品检测 | 指明对应危害、措施及现场验证/监测与判定范围 | 缩为质量/工艺指标观察，不声称完成全部危害控制 |

严重度依核心主张受影响程度判断；没有提供记录先列信息缺口，不能推定现场违规。复审核对修订流程、实际尺度、分母和结论是否一致，不仅检查作者回复。
