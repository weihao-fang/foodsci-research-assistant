# 实验设计

将研究问题转成可审查的实验方案，或依据实际方法和原始数据分析。先判断是“数据采集前设计”“已有数据分析”还是两者都有；已有数据的处理不得伪装成预先制定的计划。

## 按任务进入科研步骤

| 本次任务 | 读取与交付 |
| --- | --- |
| 拆解论文、研究问题或规划关键实验 | [研究拆解与规划](research-planning.md)：主张—实验/组件—对照—结果映射、替代解释与最小判别方案 |
| 分析已有数据、选择统计或复核分析 | [数据分析](data-analysis.md)：数据/单位审计、分析决定、实际代码与结果或待运行方案 |
| 食品与材料、微生物、营养、工程、组学/预测等交叉研究 | [领域桥接](crossdisciplinary-bridges.md)：连接假设、适用测量、独立单位与最小迁移验证 |
| 规划或生成科研图表、检查数据与图注 | [证据图表](figure-evidence.md)：科学问题、面板/数据对应、n与误差定义及真实导出检查 |

这些步骤按需进入，不强制完整管线或审稿。可用[共用研究记录](../assets/research-analysis-template.md)衔接文献、实验、数据、图表和写作，保留相反结果与未知连接。

## 选择方法

先读 [方法目录](methods.md)，按研究问题选择方法，再只读本次需要的方法文档。跨方法项目可组合有关模块，例如模拟消化后测抗氧化活性，或多糖表征后做 RAW264.7 研究；明确各环节样品、批次与独立单位如何对应，不能因跨模块重复测量增加独立 n。

目录也包括食品3D打印、发酵、斑马鱼、小鼠、功能评价、保鲜/贮藏和生产放大。先确定本次要支持的食品性能、功能或应用主张；动物模型、工业验证或完整安全期限不作为所有项目的必选环节。涉及动物时依[动物模型](animal-models.md)核对分配层级、福利与实际适用审批；审批状态不明不得填为已获批。

用户提供未登记的方法时，通过 [添加方法入口](ADD_METHOD.md) 和 [方法模板](../assets/method-template.md) 补充。自定义方法需要实际方法依据；新增目录项不表示已验证、已连接数据或已有数值分析程序。

## 数据采集前的设计

在方法指导下形成以下可交付方案。未知条件列为“待确认”，可先完成不依赖它的部分；不得套用固定样本量、剂量、时间、酶活或细胞刺激条件。

1. **研究问题与主要终点**：说明材料、比较对象、可证伪的假设及主要终点的操作性定义、单位和取样时点；区分探索性次要终点。
2. **因素与对照表**：列因素、水平、处理/对照、对照目的、测量方法和所需样品，注明来源是用户记录、已核验原始方法还是待验证建议。剂量或浓度范围须由文献、适用性和预实验支持。
3. **独立单位与重复依据**：明确食品生产批次、独立提取/消化/培养运行和技术测定的层级，解释哪个单位支持哪个推断。样本量依据目标效应、变异估计、精度或功效规划及资源约束；缺依据时提供估计/预实验路径，不能随意填 n 或用技术重复替代独立重复。
4. **随机化、区组与盲法**：说明样品分配、操作/检测顺序及编码；必要时以批次、实验日或板为区组，保留同一独立单位的配对/重复测量关系。记录不能随机化或盲法的限制。
5. **质量控制与预定分析**：定义基质空白、校准、检测范围、回收/干扰检查及缺失/排除规则。预先写主要比较、效应量/不确定性表达、实验单位、配对或重复测量结构、统计模型的适用条件与多重比较处理；仅有描述性目标时明确写描述性分析。
6. **来源与不确定性**：给可核验的方法来源与实际查阅范围，列待确认信息、方案限制和需先做的适用性验证。无法查阅的文献只能作为待核验线索，不能补造 DOI、参数或已核验状态。

方案输出包括上述问题说明、因素/对照表和分析计划，并区分“拟开展”“已执行”“已产生数据”。不把方案写成已完成的实验或结果。

## 已有数据分析

先核对方法记录、数据来源、独立性、单位、空白/校准、处理配对及缺失信息，再按选定方法文档分析。保留原始值、转换公式和来源映射；不为预期趋势删数，不虚构效应、p 值、置信区间、显著性或机制。

读取 [数据契约与计算范围](data-contract.md)。随包 `scripts/analyze.py` 仅支持 `digestion` 和 `raw` 的描述性模式，命令从Skill根目录执行；不计算推断统计。其他登记模块没有随包专用数值程序，不能把鱼鼠、发酵或贮藏数据套成raw模式。通用数据分析可在宿主具备工具、实际数据与适用方法时依[分析流程](analysis-workflow.md)另写并执行本任务代码，包括有依据的统计；不能声称这些临时代码是已内置的通用引擎。无执行条件时交付待运行方案并注明未执行。

分析交付包括数据审计、独立单位层级、计算/统计方法、实际结果、输入输出定位和证据边界。结果段落只写数据支持的比较；若需要中英文稿件或投稿审查，再衔接对应 Skill，不把体外测量直接写成人体功效。
