# 食品保鲜、贮藏与货架期评价

提供设计及已有数据审查指导，无随包专用计算器。“保鲜/贮藏”是本模块范围；品质变化、微生物安全和商业标签期限须分别提出证据要求。

## 先界定目标与条件

明确食品/成熟度/配方、生产批次、初始状态、保鲜处理、对照、包装和拟用情景。记录密封/开封、冷藏/冻结/解冻等状态、实际温度曲线及必要的湿度/光氧条件；未提供时列待确认，不套统一温度或天数。

先选择目的：比较给定条件下的品质保持、观察腐败/目标微生物，还是要建立适用于流通/消费的货架期。色差、质构、失重、氧化或酶活等作为主要终点时给操作性定义、单位和评价标准；不把有利变化自动叫作安全期限延长。声称标签期限时须有适用产品、危害及目标地区依据。

## 设计与独立单位

- 按问题配置未处理/载体/常用处理或包装对照，除目标因素外尽量匹配温度、包装与操作。若处理和包装同时变化，评价整体方案或分离因素，不把差异全部归于单一成分。
- 以多个独立生产/采收批次覆盖拟推断变异；同批多个包装是子样本还是独立处理单位，取决于处理在哪一层分配。记录批次、包装、贮藏设备及位置的对应关系，不将样品数默认当独立批次数。
- 处理若只对应唯一冷库/箱体，温度/设备与处理可能混杂；同一设备中相同温度下分配不同包装处理，不因此一律失去包装层级的处理重复。按实际设计定单位、区组及适用范围。
- 预先区分同包非破坏性跟踪、各时间点独立取包的破坏性测量与同包多个测点。破坏性测量不虚构为同包配对，同一批次跨日仍保留批次关联；重复读数不增加独立n。
- 时间点、批次数与每点子样本量根据预期变异、主要比较和临界变化区域规划；没有依据先做范围/精度预实验，不指定固定“三重复”。分配和检测顺序尽可能随机，适用时编码盲评。

## 分析取舍

按实际独立单位汇总原始值及不确定性。处理×时间问题可考虑包含批次/设备/包装层级的适当模型；同包重复测量保留相关结构，破坏性取样根据实际批次区组安排分析。不能机械套配对t检验、把时间点当独立批次，或为获得显著性选模型。

设定可解释的质量终点、失效判据和起算时间；若需估计到阈时间，说明阈值依据、删失/未达阈情况及估计不确定性。观察期未失效只能支持该期内结果，不能无条件外推更长期限。加速试验/预测模型用于目标储存条件前需验证假设及外部适用性，不能仅凭高拟合度证明真实货架期。

微生物数据先核对目标、取样量、稀释/计数方法、单位和检出/定量限；未检出不等于绝对为零，好氧菌落总数不能代替全部致病菌。是否需要特定挑战或耐久性研究取决于拟作的安全主张和实际危害，不强迫仅比较品质的论文一律补全病原试验。此模块不提供病原培养/挑战操作流程。

## 审稿与最小修复

| 检查 | 最小必要修复或结论边界 |
| --- | --- |
| 批次、包、设备和时间是否混淆 | 依据实际记录重建层级、重新汇总/分析；无法分离的混杂如实限定，不能事后把子样本改名为新批次 |
| 实际条件与所称应用是否一致 | 补可追溯条件/处理记录；证据不足时将结论限于实际包装、温度及观察期 |
| 感官/理化品质是否被改写为食用安全 | 纠正主张；保留品质贡献。只有坚持安全期限时才要求与危害对应的验证 |
| 开封、解冻或重新包装后的期限是否沿用密封数据 | 核对条件变化及证据；不能默认同一期限适用，也不编造统一折减系数 |
| 修订是否真的补了批次/时间证据 | 先查修稿及记录再查回复；补充拟开展的试验不当作已完成 |
