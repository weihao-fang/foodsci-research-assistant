# 食品领域的选择性审查

先按食品对象、研究问题及作者主张选相关模块，不把以下内容当成每篇论文都必须完成的实验清单。检查顺序为“样品与基准→处理/对照→测量适用性→实验单位→结论”；发现问题仍须回到本稿真实定位和证据。

## 共同基础

原料/品种/部位、食品状态与来源批次是否足以界定对象；采样、加工、提取、纯化、消化及保存过程能否追踪。浓度与含量须有真实分母及干湿基/蛋白基/提取物基，体积、稀释和回收是否一致。若不同处理只比较吸光度而校准响应不可比，不能直接等同于真实含量差异。

工艺条件、溶剂、pH、盐度、温度和基质是否与对照相匹配；原料批次、加工运行、检测复测的层级是否混淆。共提物、残留酶/胆盐及颜色浑浊等是否可能解释观测。任何未报告条件先标缺口，不擅自填常用值。

## 按主张选择

| 领域 | 应检查的证据链 | 典型越界及可行修复 |
| --- | --- | --- |
| 食品组成与分析方法 | 样品身份与取样→提取/前处理→校准、选择性、基质影响、量程/单位→定量。只有声称新/改进方法或关键测量依赖时，按目的检查回收、精密度、检出/定量能力及适当参照 | 一个峰或总量不自动证明精确组分身份；标准溶液性能不自动代表真实食品基质。补针对性验证或限定为当前方法的操作性指标 |
| 食品蛋白与肽 | 原料及蛋白/干物质基准→水解/分离和酶制剂贡献→跨水解程度的定量适用性→结构、聚集/界面等证据与功能条件 | 小肽和完整蛋白的比色响应不能默认相同；溶解性、乳化、凝胶、消化是不同终点。相关谱图变化不直接证明某结构导致功能。参阅[蛋白方法](proteins.md) |
| 多糖与食品胶体 | 粗提物得率、总糖/蛋白及共提物→所声称分子量、单糖/连接/构象等的相应证据→同浓度、pH、离子环境和加工条件的流变/胶体功能 | 总糖不等于纯多糖纯度，粗提得率不等于纯多糖得率；单一FTIR不能独立确定精细连接结构。不强制所有稿件做全套结构分析，要求由具体结构主张决定。参阅[多糖方法](polysaccharides.md) |
| 抗氧化与营养功能 | 明确DPPH/ABTS/FRAP等测量机理→对应空白、本底、标准、时间和浓度→校准/剂量范围→所声称活性层级 | FRAP还原能力不等同自由基清除率；缺少样品本底不能补零，未覆盖50%不能报无条件精确IC50。化学能力不直接证明细胞保护或人体健康。参阅[抗氧化方法](antioxidant.md) |
| 体外消化与细胞衔接 | 模型版本和人群适用性→阶段、酶活、pH、时间、终止/分离及质量/体积基准→细胞接触的消化基质与匹配空白→主终点和替代解释 | 静态阶段终点不直接给出生理消化动力学；释放/可及相不等同人体吸收或生物利用度。高初始氨基水平不能自动解释成新增消化更多。参阅[消化方法](digestion.md) |
| RAW264.7等细胞功能 | 模型身份和实验质量→样品/消化液/刺激与溶剂对照→检测干扰与适当活力/损伤证据→独立培养、板与技术孔→实际炎症/机制指标 | NO相关读数降低可能有活力或检测干扰解释，不能直接证明机制或人体治疗；多糖等样品的内毒素污染是按主张审查的可能混杂，不可默认已存在。必要时要求排除竞争解释或降级主张，不能默认补全通路/动物试验。参阅[RAW方法](raw2647.md) |
| 加工、乳液与贮藏 | 独立生产/制备批次→工艺、配方及对照→油相/蛋白浓度/均质/包装与温湿度、光氧条件→时间内重复测量→实际稳定性或品质终点 | 多个瓶/时间点不自动等于独立批次；单一终点或加速条件不能直接支持未测条件的货架期。稳定性提高不自动证明特定分子机制，结论应限于实际体系与观察期 |
| 食品3D打印 | 墨水批次/配方→流变与适用条件→打印设备/参数/运行→几何与保形指标→后处理后的实际食用性能 | 多件打印不自动增加独立运行；成形良好不证明营养、吞咽安全或工业可用。补测量定义/运行记录，或收窄为实际条件下可打印。参阅[食品3D打印](food-3d-printing.md) |
| 食品发酵 | 基质与菌株/群落→接种/时间/温度等运行条件→匹配对照→独立发酵器/批次→代谢、活菌或品质终点 | 酸化/基质改变与菌株特异效应需区分；分装和时间点不充当新发酵批次。活菌数、代谢物和体外活性不直接证明益生功效或安全。参阅[发酵方法](fermentation.md) |
| 斑马鱼食品功能研究 | 阶段/品系/来源→暴露途径/基质与模型对照→缸/板/个体分配及窝/批次→盲评功能终点→模型适用性 | 处理与唯一缸/批次混杂时不能把所有鱼当独立处理重复；单鱼独立分配也不能一概判为缸n=1。荧光、行为或表型不自动证明人体效益；不默认幼鱼免伦理。参阅[斑马鱼](animal-models.md#斑马鱼) |
| 小鼠食品营养/功能研究 | 品系/性别/日龄→饲粮/载体、摄食与实际暴露→个体/笼/窝分配→功能终点与福利→食品相关解释 | 群养共同饲粮的笼层级摄食不能变成每鼠独立摄食；给药个体随机化也不自动被笼数替代。组织/视野不是新增动物，模型改善不直接确证临床疗效。参阅[小鼠](animal-models.md#小鼠) |
| 食品功能评价 | 明确拟保留主张→操作性主要终点及适当对照→基质/剂量与测量适用性→化学/细胞/动物/人体证据层级→效应与不确定性 | 功能、机制和安全分别论证，不用指标数量代替证据。食品功能研究不以补动物/人体为默认门槛；保留较窄主张可构成有效修复。参阅[功能评价](functional-evaluation.md) |
| 保鲜、贮藏与货架期 | 产品/包装/初始批次→实际环境与期限→破坏性或同包跟踪→品质/微生物终点→适用储运情景 | 感官、色差或失重改善不证明病原安全或商业期限；破坏性取包不构造同包配对，但批次跨日关联仍须保留。限定品质结论时不强迫完整挑战试验。参阅[保鲜贮藏](preservation-storage.md) |
| 食品生产与工艺放大 | 产品与单元操作→原料/过程批次→质量/物料衡算的真实分母→尺度/产线与过程控制→质量、安全及经济验证范围 | 连续相邻样点不等于多次独立生产；实验室得率不直接证明工业产能、能耗、成本或放行安全。补口径/验证或限定规模；不把每个步骤都指定为CCP。参阅[生产放大](production-scaleup.md) |
| 配方与工艺优化 | 混料比例/工艺因素及可行约束→实际随机化与整区/运行内单位→可估主效应、交互/曲率→模型诊断与新批次确认 | 总和受约束的比例不按独立因素解释；运行内多样品不补足整区重复；拟合最优点不等于已验证最优。参阅[方法选择](scientific-methods.md) |
| 菌群、组学及食品预测 | 特征/样本ID与独立单位→组成、计数或定量信号→QC、注释和比较族/FDR→设计相符的分析/验证→拟保留主张 | 相对丰度不等于绝对增长；TPM不替代RNA计数模型输入；PCoA/富集不等于机制。同批复扫跨测试侧、全数据筛特征或反复挑测试集均会影响预测评价，先复核流程或收窄结论。参阅[分析流程](analysis-workflow.md) |
| 食品微生物与安全 | 先明确目标菌/毒素和检测/挑战目的→实际方法版本、基质、取样/稀释及培养→适用对照、计数/定量限与单位→未检出和数据转换→拟作的安全结论 | 无菌落/未检出不等于绝对为零；好氧平板计数不证明全部病原阴性或食用安全。法规判断需对应地区、食品类别和现行限量，不套固定阈值；不同方法计数规则不得混用 |
| 感官与消费者研究 | 明确辨别、描述或喜好目的→评价者来源/训练适配→呈样、编码/盲法、顺序和条件→受试者内重复及统计→感官主张 | 训练小组描述不能直接代表消费者喜好，仪器质构不代替感官接受度。按实际人类参与研究和适用政策核对同意/伦理；本包未核验独立感官标准，不能补造标准号或要求所有食品实验同一审批 |

## 结构—功能、机制及模型外推

先分清“同时变化”“有预测关联”“有可区分替代解释的因果/机制证据”。分子对接、谱图相关、单一抑制指标或组学富集本身都不能自动完成机制证明；也不应反过来强迫只报告现象的论文增加机制研究。必要证据取决于作者拟保留的论点。

Food Chemistry偏重食品化学/生物化学或分析贡献，Food Hydrocolloids强调食品胶体的理化特征与解释；这属于各刊实际可读范围的定位线索，不是全食品领域统一门槛。未查当前完整指南时，不给“全部合规”结论。适用来源及本轮获取限制见[来源说明](peer-review-sources.md)。
