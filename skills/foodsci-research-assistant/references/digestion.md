# 模拟消化：实验设计与数据分析

目标是把实际测量、可计算的指标和研究者的解释分别写清楚。原始文件、方法版本、样品批次和分析步骤必须能追溯；缺失的参数标为“未提供”，不得用常见配方或文献数值补成已做实验。

## 实验设计：数据采集前

先将研究问题限定为适合该模型的终点，例如比较某材料在明确消化阶段与操作性级分中的分析物量。按主 Skill 的方案要求列研究问题、因素/对照、独立单位、随机化/区组、主要终点与预定分析；不以体外阶段读数预言人体吸收。

设计表中明确食品批次与独立消化运行的层级、组间比较因素及水平、阶段/取样点、待检测的总消化液或分离组分、匹配酶/胆盐与样品基质空白，以及校准/回收验证。根据将使用的原始方法和样品适用性决定条件；尚未核验的酶活、pH、时间、体积与用量标为待确认。若同一次运行跨阶段取样，在取样/补液与后续分析中保留依赖关系。样本量依据批次/运行变异、主要比较和精度/功效目标，不能用增加同一消化液测量次数替代独立运行。

## 已有数据分析：开始前

先读取 [数据契约](data-contract.md)，按需读取 [指标与证据边界](digestion-interpretation.md)。确定用户要比较的是消化阶段末端读数、释放量、回收率、bioaccessibility，还是蛋白水解程度（degree of hydrolysis, DH）。这些指标不能互换。

核实以下最小信息；部分缺失时可继续做不依赖该信息的检查，并单列受阻的计算：

- 食品/提取物身份、批次、初始投料质量及干基/湿基，分析物和检测方法；原始读数是否已校准、扣空白或校正稀释。
- 实际消化方法、版本及偏离；各阶段、终点取样与终止方式；最终体积、取走体积、补液和稀释；测的是总消化液、上清、胶束相还是其他分离组分。只审核作者提供的操作记录，不能据“使用 INFOGEST”自动补全试剂、活性或条件。
- 独立食品批次、独立消化运行、同一消化液的技术测定分别有几个；各阶段是否来自同一消化运行。实验单位取决于问题：多个消化管不自动等于多个食品批次。
- 与消化液、酶/胆盐和分析基质匹配的空白，以及标准曲线、检测范围和质量控制。缺少基质干扰证据时，限定为“未确认无干扰”。

## 描述性分析

只有宿主实际能访问Skill 文件且有 Python 执行环境时，才从Skill 根目录运行下列命令；否则给出本地运行说明，明确尚未执行。不得宣称已连接实验仪器或实验记录。

```text
python scripts/analyze.py digestion --input data.csv --output new-digestion-result.json
```

CSV 必须包含 `experiment_id,sample_id,stage,replicate_id,readout,value,blank,unit,dilution_factor`。`sample_id` 是跨实验保持一致的配方/条件标签；`experiment_id` 是明确记录的独立运行标识；`replicate_id` 标识技术测定，不能靠改编号增加独立重复。仅按契约映射字段，保留原始文件和映射记录。

本工具只做 `(value - blank) × dilution_factor`，在实验内汇总技术测定，再跨实验给描述性统计。它不做标准曲线拟合、单位转换、体积/质量换算、生物可及率、DH 或显著性检验。输入吸光度时，输出仍是吸光度尺度，不能改称分析物浓度。

检查重复标识、缺失/非有限数、单位冲突、校正重复应用和负的校正结果。未知空白不能填 `0`；零空白必须有实际依据。不要把负数截成零，不要为获得预期趋势删除数据。技术测定先汇总，分别报告独立运行数和技术测定数；单次独立运行不能报告跨运行 SD。各阶段来自同一运行时保留配对关系。

计算量或比例时另列完整公式和输入来源：浓度比较必须考虑阶段稀释；量的计算通常还需要对应组分体积。`dilution_factor` 的含义必须明确，不能把检测前稀释与消化过程体积变化重复计算。初始量、体积、组分定义或方法校准缺失时，停止该派生指标的计算，仍可报告已支持的读数。

## 交付结果

提供数据审计表、技术测定汇总、实验级结果、描述性汇总及所用公式。每个结果对应来源文件/工作表/行、分组键和处理规则；实际运行时记录命令、输入文件哈希（可获得时）和输出路径。将缺失信息、排除记录及原因附在结果旁。

写中英文结果时填写真实的指标、单位、独立重复数、技术重复数及 SD 的层级；没有推断检验就不写“显著”、p 值、置信区间或星号。可用“在该体外模型与所测终点下观察到……”/“Under the tested in vitro conditions…”界定范围。INFOGEST 静态模型的阶段终点不能直接代表人体吸收、生物利用度或临床获益；其时间序列也不能直接称为生理消化动力学。具体边界和核验来源见参考文件。
