# 食品功能评价：把主张与证据对应

用于营养/健康相关食品研究的设计与结果审查。先区分营养组成、材料加工功能、模型生物活性、人体功能与监管声称。
乳化/凝胶等技术功能按 [蛋白实验](proteins.md) 等实际方法评价；不能因同称“功能”而套用生理功能终点。
本模块没有专用计算程序；不把任何新模型数据塞入 RAW264.7 或模拟消化 CSV 后宣称已完成该模型分析。

## 开始前的必要输入

- 预期主张的原句、使用对象/目标人群或模型、食品形态、使用场景、实际食用量/暴露和研究目的。
- 样品身份、批次、组成、提取/纯化/发酵/加工历史、检测基准与在相关环境中的稳定性。
- 从候选功能选一个可检验的主要问题，列主要终点、测量方法、方向及有意义的效应/目标精度；其余区分次要或探索性。
- 现有证据到哪一级、每条主张对应哪份原始记录；阳性、阴性和相互矛盾的结果均保留，不按期望功效筛指标。
- 实际分组、处理分配、批次、个体/池/孔/技术复测层级、时间线及原始终点；缺失数据不补成零或“已合格”。
- 若涉及人体或动物，先核实相关机构/地区要求、审批/同意及适用方案；不虚构注册、批准或执行记录。

## 选择证据层级，而非自动升级全部模型

| 层级 | 可回答的问题与必要检查 | 不能直接推出 |
|---|---|---|
| 化学/生化 | 明确反应体系中的清除/还原、酶抑制或结合等；检查校准、阳性/载体与样品空白、检测范围和基质干扰 | 人体抗氧化、降糖/降压功效、实际吸收或长期安全 |
| 消化/运输等体外模型 | 明确阶段与级分中的释放、可及性或模型转运；记录物料/体积基准、质量平衡及模型屏障有效性 | 释放率等于吸收率、体内生物利用度或临床获益 |
| 细胞 | 特定细胞与暴露时序下的功能读数；核对活力/损伤、样品干扰、培养运行、对照与剂量可达性 | 单一炎症/ROS/表达读数就确证通路因果、人体疗效 |
| 动物 | 明确物种、阶段/模型、分配单位和暴露下的预定终点；评价摄食、代谢和模型混杂 | 人体可用剂量、健康人长期获益、食品安全或获准声称 |
| 人体 | 与目标人群、食品、剂量、比较和持续时间相符的功能证据；核对设计、依从性、共干预和有效终点 | 不相同食品/人群/用量的自动外推，或研究结果本身即获批准 |

这些是证据范围，不是“体外→动物→人体全部必做”的流水线；是否需要追加证据取决于保留的核心主张。
动物或人体并非所有食品基础研究的必要补实验；作者可将结论限定在已研究体系，说明何种外推尚待验证。
人体研究也须评价偏倚、测量与因果识别；观察关联、对照干预和机制研究贡献不同，不能只凭“人体”二字排序。
食品组成/营养含量的确认与功能获益的证明分开；提取物或高浓度纯成分的活性不能原样写成整食品食用效果。

## 食品问题与终点适配

- 抗氧化：按 [抗氧化实验](antioxidant.md) 区分反应机理；DPPH/ABTS/FRAP 等读数只按该测量含义解释。
  细胞 ROS/抗氧化酶改变与实际损伤保护分开；不把总抗氧化能力或酶表达上调单独当人体保护获益的证明。
- 炎症/免疫：区分降低特定炎症读数、免疫调节与“提高免疫力”；同时检查毒性/细胞数变化和检测干扰。
  对 RAW264.7 使用 [相应模型](raw2647.md)，不把 LPS 刺激细胞结果直接换成人体免疫或疾病治疗结论。
- 糖脂代谢：体外酶抑制、吸附或染色与餐后血糖/血脂、体脂或代谢功能分别定名；核对单位、暴露与背景膳食。
  减少摄食、体重或染色信号可能有多种原因，需与研究目的相符的混杂检查，不自动等于减脂、降糖或健康改善。
- 肠道/微生物：菌群组成、代谢物与宿主功能分别评价；相对丰度和 SCFA 浓度变化本身不确证“益生”或宿主受益。
  体外发酵、宿主体内和人体终点不要混用；机制因果主张才按问题考虑必要干预与替代解释，不普遍强制移植/组学。
- 蛋白/肽/多糖：结构、分子量或纯度关联与活性归因分开；共提取物、载体、残留试剂及不同批次组成可能影响终点。
  [模拟消化](digestion.md) 后检测须明确实际测试级分与剂量，不能把释放、吸收和活性保留混为一个指标。
- 疲劳、认知/行为或其他复杂功能：预定与主张相符的功能终点；活动量、体重、应激、感觉/运动障碍可能改变读数。
  不拿一个分子标志物替代完整功能，也不列未经实际来源和方法适配核验的通用行为造模参数。

## 设计与分析条件

对照要回答具体问题：如载体/基质、未处理或模型、加工前后/发酵前后、匹配食品与适用阳性比较；不机械要求每类都出现。
食品替换或添加应考虑能量、营养素、适口性及其它成分共同变化；以真实科学问题决定匹配、协变量或对照设计。
预先说明主要比较、样本量依据、随机化/区组和盲法适用环节；参数来自有适用依据的原始方法或预实验，不能编固定剂量/n。
食品批次、独立制备/培养、动物或参与者与重复读数分层；参见 [动物模型](animal-models.md) 的缸/笼/个体分配规则。
一批提取物测试许多孔不支持多个独立食品批次的推断；同一对象重复时间点保持配对或纵向相关。
终点类型、分布、依赖结构、缺失/排除及检测限决定可用分析；报告真实效应和适用区间，不替汇总图编 p 值。
多个终点/剂量/时间点需计划比较与多重检验处理；探索结果如实标记，不能挑一个显著结果重写为事前主要功能。
机制判断区分关联、干预和特异性；单次组学富集、对接、单一抑制剂或表达改变不能独自确证整条因果链。
功能与安全另列证据：有效终点、未见特定毒性和可接受食用风险不能互换，也不以功效阴性就认定安全。

## 审稿修改与最低修复

按“主张原句 → 稿件/原始数据定位 → 适用模型/终点 → 已支持与缺口 → 修改方向 → 关闭标准”输出，先处理核心问题。
缺少材料时请求实际记录并标记未评估；存在证据矛盾时指出准确位置，不将二者都写成已证明实验错误。
优先核对对照、干扰、单位/分母、独立单位、暴露和现有数据重分析；不先开全套指标、组学和动物补实验清单。
若现有设计只能支持模型内观察，收窄标题、摘要与讨论是一条可接受修复路径；若坚持人体/机制主张，再明确必要证据。
既有可比证据或有依据的反驳可以解决意见，不能只接受某一种技术路线；修订后以原问题 ID 和关闭标准核对正文。
商业功能/健康声称应先确认目标司法辖区、产品类别、具体原文和当前官方规则，另行核验；本模块不作批准保证。
欧盟 EFSA 的要求仅作该辖区实例，不能作为中国或其他地区保健食品/普通食品的统一准入规则。

## 来源与访问范围

核验日期：2026-10-18。本框架将来源支持的边界与食品方法审查原则结合；未逐项核验全部功能的专用检测标准、人体方案或各地法规。

- [EFSA：Health claim application procedure](https://www.efsa.europa.eu/en/applications/health-claim)：实读网页的科学证据与申请范围段；支持食品/成分特征、人体相关功能、人体有效性证据及生物学合理性的区分。范围为欧盟食品健康声称，不代表所有食品论文必须提交申请。
- [EFSA NDA Panel，2018：抗氧化、氧化损伤与心血管相关声称指导](https://efsa.onlinelibrary.wiley.com/doi/10.2903/j.efsa.2018.5136)，DOI `10.2903/j.efsa.2018.5136`：实读出版页正文第 2、3.1、3.1.1–3.1.2 节，核对体外抗氧化、血浆总抗氧化能力、营养素必需性与人体损伤保护的差别；未把其所有具体终点扩成通用必测清单。
- [NC3Rs EDA：实验单位](https://eda.nc3rs.org.uk/experimental-design-unit)：实读单位、重复观测和多层设计示例；用于功能实验独立性检查，不替代人体试验的专用设计与伦理核验。
- [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines)：实读清单及相关解释页；用于动物部分的透明报告与设计审查，不据此推断人体功能。
- [模拟消化证据边界](digestion-interpretation.md)、[RAW264.7 证据边界](raw2647-interpretation.md) 和 [抗氧化实验](antioxidant.md)：沿用随包模块各自已记录的来源与访问边界；登记链接不表示本轮重新核验其中全部外部来源。
