# 成稿与中英一致性复核

本文件用于较长文本、双语稿或涉及数字和结论的修改。简单句子润色不必输出整张核对表。

| 核查项 | 通过条件 |
|---|---|
| 数值与单位 | 原稿与改稿逐项一致；格式变换不会混淆 mg/mL、μg/mL、百分比与百分点 |
| 实验单位 | 独立实验与复孔分别表达；n 的含义未被改写 |
| 统计 | 保留检验、比较对象、P值、区间和SD/SEM类型；新引用数值有实际分析记录，不由润色补造 |
| 检测与推断 | 直接测量、推断和机制假说可区分；不新增未测指标 |
| 引文 | 编号/作者年份及其支持的论点仍对应；待核验引用未变成已证实来源 |
| 模型 | 食品体系、模拟消化、细胞、动物和人体证据没有互相替代 |
| 双语 | 数字、方向、程度、时态、否定和不确定性对应；术语在同一稿件内一致 |

需要给作者说明实质修改时，可用下表，避免为纯标点修改制作冗长记录：

| 原文定位 | 修改后的关键表达 | 修改理由 | 证据来源/待确认点 |
|---|---|---|---|

缺失事实用明确标记，例如“[待补：独立实验次数]”“[待核验：该引用是否支持人体结论]”，不要伪装成正文事实。若原文包含不受证据支持的强结论，在交付保守改稿的同时列出缩小结论的理由；不要只改善其语言而保留误导性含义。

示例仅演示语义规则，不代表实验结果：作者明确写“3 次独立实验，每次 3 个复孔”，英译应保留这两层信息；不可写成 n = 9 independent experiments。原文只测量 NO 时，不新增 NF-κB、细胞因子或其他未提供结果。

较长论证另核对：每个主要主张能否回连实验/数据/图表；支持范围有没有因讨论或跨学科术语而扩大；相反结果与边界证据有没有被隐藏；引用的分析是已执行还是计划；最强可支持结论是否仍保留实际食品体系、模型、剂量/过程和批次边界。原始测量、计算效应、机制解释和应用意义分开组织，不能用某种叙事模板替代证据。
