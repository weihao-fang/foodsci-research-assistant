# 生物食品研究的方法选择

下表列出常见设计与分析结构，可按当前问题选择、组合或采用其他适用方法，交付能改变研究决定的内容。这里是设计与分析依据；实际计算依宿主工具和真实数据执行，随包计算范围见[分析流程](analysis-workflow.md)。

## 先固定要回答的效应

用一句话写“在什么研究对象/模型、什么独立单位和时点，比较什么处理，估计什么变化”。区分描述、预测和因果问题。食品工艺优化常关心得率、保形或品质；功能研究常关心实际暴露后的生物响应，两者需要不同对照和验证。

| 研究结构 | 会改变方案的判断 | 最小交付 |
| --- | --- | --- |
| 配方与工艺优化 | 总和受约束的蛋白/多糖/水比例属于混料；温度、压力等属于过程因素。筛选设计查混杂/别名关系；优化设计查曲率、可行区与独立确认 | 因素、约束、拟估交互/曲率和可估性；将模型推荐点与新批次确认分开 |
| 难改变因素与批次 | 烘箱温度、设备设置或成批发酵条件可能在整次运行分配，包装/测定在运行内分配；按真实分配建立裂区/嵌套层级 | 各因素的分配单位、随机化限制及误差层；不能用运行内大量样品充当运行重复 |
| 贮藏/发酵/动物时间数据 | 同对象复测、同批破坏性取样和独立运行不同。先决定关注指定时点、变化量还是处理×时间 | 取样图及主要比较；选择相应纵向/分层分析，保留批次、容器或个体依赖 |
| 菌群与相对组成 | 相对丰度上升可能来自其他组分下降。先核对测序深度、阴性/QC、特征过滤和零的含义，再选有依据的组成分析或计数方法 | 原始特征表与样本映射、分母/零处理、比较族/FDR；涉及绝对增长时补相应总量依据 |
| 转录组与代谢组 | RNA差异计数模型使用适用的未归一化计数/经认可导入的估计计数；TPM、FPKM和热图缩放值不能代替。代谢特征保留空白、QC、漂移和注释证据 | 输入尺度、参考/注释版本、设计与对比、效应及校正P值；富集交代背景与ID映射 |
| 食品预测与高维筛选 | 按未来预测对象划分批次/来源/时间；缺失填补、缩放、降维、筛特征与调参在训练侧完成 | 分组划分、简单基线、内层调参与外层评价或独立测试、误差/不确定性；报告未覆盖的新场景 |

距离分析先对齐样本ID和实际距离定义。PERMANOVA用完整距离矩阵，结合组内离散程度判断；PCoA图上的分离不能替代检验。配对/纵向设计先明确可交换单位及受限置换规则，不能套不支持该结构的逐样本自由置换。零替换、筛选及变换须有理由和敏感性记录，不能把所有零机械加一。

## 样本量先服务研究决定

确定目标是检测有意义差异、估计到所需精度，还是检验等效；等效界值须有科学依据。给出目标效应的实际单位、变异来源、主要比较和误差控制。配对研究需要差值变异；聚类/纵向研究需要相应相关结构，不能照搬独立样本公式。

变异与效应来自可比先验、预实验或明确的决策阈值，并给合理范围的敏感性分析。没有依据时先给预实验或精度规划路径。若实际执行模拟规划，记录数据生成假设、计划分析、零效应校准、拟合失败和Monte Carlo误差。固定资源下可报告可检测效应/精度；已完成研究优先解释效应区间，不用观察效应倒算“事后功效”证明样本充足。

## 把组学发现变成可判别的机制

按实际系统、干预与响应，只验证本次主张需要的连接；食品研究例如“加工→结构→消化→生物响应”或“发酵→代谢物→宿主响应”。先查同批样品、质量/干湿基、暴露剂量和时间是否衔接，再列主要竞争解释。中介物与响应共同变化只支持候选关联；支持特定归因时，可据目标选择匹配基质/剂量、目标去除与补回、正交测量或独立批次确认。每种处理也可能改变其他成分，所选对照应能区分主要解释。

先修测量干扰与混杂，再决定是否增加昂贵组学或动物实验。机制图把实测连接、候选关联与未测假设分开；阴性结果可削弱哪条连接要写清楚。具体应用见[领域桥接](crossdisciplinary-bridges.md)。

## 方法来源

2026-10-23核对下列公开原始方法/官方文档，提炼为食品研究决策；未打包其软件、数据库或全文。网页版本不代表用户本机已安装版本。

- NIST/SEMATECH e-Handbook：[混料设计](https://www.itl.nist.gov/div898/handbook/pri/section5/pri54.htm)、[嵌套与裂区](https://www.itl.nist.gov/div898/handbook/pri/section5/pri55.htm)，支持配方约束与分配层级选择。
- scikit-bio：[组成统计](https://scikit.bio/docs/latest/generated/skbio.stats.composition.html)、[PERMANOVA](https://scikit.bio/docs/latest/generated/skbio.stats.distance.permanova.html)、[PERMDISP](https://scikit.bio/docs/latest/generated/skbio.stats.distance.permdisp.html)，支持相对组成、距离与离散程度分析；具体置换仍需匹配设计。
- Bioconductor：[DESeq2官方分析文档](https://bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html)，支持计数输入、多因素/配对设计及明确对比。
- scikit-learn：[防泄漏](https://scikit-learn.org/stable/common_pitfalls.html)、[交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)，支持训练内拟合、分组与验证边界。
- 方法组织借鉴K-Dense的Scientific Agent Skills相关技能。Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026). *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. [arXiv:2609.00065](https://arxiv.org/abs/2609.00065)。本页核对时记录为v2；项目出处与第三方权利见[第三方说明](third-party-notices.md)。
