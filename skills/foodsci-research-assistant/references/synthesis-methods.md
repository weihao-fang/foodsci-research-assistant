# 从证据提取到综述综合

用于需要整理多篇文献、形成主题论证或写综述正文的任务。按本次问题采用相关步骤，短段落不必重建完整系统综述。

## 类型与问题对齐

- 叙事/批判性综述围绕概念、机制、方法或进展形成判断，交代实际选材范围；选材透明不自动意味着系统穷尽。
- 范围综述说明研究对象、概念与情境，绘制研究类型、测量、分布和缺口；预先定义提取字段，避免把研究地图改成未经评价的疗效结论。
- 系统综述先固定可回答问题、纳排与预定综合，再按实际协议执行检索/筛选/评价；协议修订保留时点、内容和理由。未注册不得写成已注册。
- 定量综合回答有共同估计目标的数值问题；它可以是系统综述的一部分，也可能因不可比或缺数据而不实施。本插件不自带元分析计算引擎。
- 微生物、结构机制或材料工程问题可用“对象/体系—改变—比较—测量—适用情境”定义，不为适应模板补入不存在的临床人群或干预。

## 最小可追溯提取

使用[工作表](../assets/review-evidence-template.md)，已有可靠台账时直接复用。检索和逐条核验细节交给[文献检索与核验](literature.md)。

1. 检索保留平台/接口、实际语法、日期及日期字段、过滤、报告总数/实际导出、原始文件与截断失败；web发现、题录身份、摘要和全文是不同访问层级。
2. 去重只处理重复记录；按共同样本、队列/试验标识、条件与时间关联研究和报告。同一研究的多个结果可分别提取，但不能当独立样本反复加权。
3. 每条结果对应模型/对象、处理/暴露、比较、独立单位/n、设计/批次、测量、结局/时点、原值或效应与区间、原文定位；保留作者结论与本次解释的区别。
4. 元数据冲突、仅摘要、全文未获取、原文未报告、未测量和不适用分别记录；没有读到的方法不能写成未实施。
5. 报告完整性、偏倚和证据体确定性分别评价。按设计、具体结局/比较选工具并记录版本/理由；GRADE用于适用的结局/比较证据体，不是通用单篇分数。

## 处理异质性与矛盾

先确认所谓“相反”是否指同一比较方向、同一结局、同一时间与同一测量尺度。核对处理组/参考组、湿干基、浓度/总量、百分比/百分点、SD/SEM和配对结构，不能靠改写统一不同含义。

| 差异来源 | 提取与写作动作 |
| --- | --- |
| 模型、物种、人群、组织/细胞、食品基质 | 按证据层级或体系分层；写明结论适用对象，不把层级并列当成功能迁移成立 |
| 加工、剂量、暴露与取样时间 | 比较真实过程/范围；可能的非线性或时间差异先作为待检验解释 |
| 检测、归一化、参考注释/数据库 | 区分同名指标的操作性定义；不能只换单位就声称可比 |
| 独立单位、批次/配对、设计和偏倚 | 判断精度与可迁移性，保留重叠样本；小样本、混杂不能靠多数论文抵消 |
| 效应方向、幅度与区间 | 展示同方向但不精确、方向不同或无法判定的实际情况；不只比较P值 |

矛盾记录保留两侧来源与原值/定位，标为“条件差异可解释/仍有冲突/可比性不足/尚未评估”。能解释的差异写出依据；未知原因不能用猜测填成机制。

不能合理合并时采用分层证据表和叙事综合。需要数值转换或元分析时转[数据分析](data-analysis.md)：预定效应尺度、依赖结构、异质性/敏感性与缺失证据处理，并保存实际执行记录。没有原始信息不补算方差或重叠相关；不能用随机效应名称掩盖不可合并。

## 写成主题段落

每段服务一个判断而非一篇论文。可按下面的关系组织，依据证据删去不适用部分，不机械套四句话：

1. **提出主题判断**：回答本节问题，范围与证据相称，例如哪些测量表现出较一致变化、哪类方法仍不能区分竞争解释。
2. **跨研究比较**：把可比研究放在同一比较轴上，写方向、幅度/范围、条件与相反结果；仅有摘要时不补正文细节。
3. **解释异质性**：指出有证据的模型、测量、剂量或设计差异；假设性的解释明确为候选，不把跨文献相关写成已证实原因。
4. **推进论点**：说明该比较如何改变机制理解、方法选择或应用判断；必要限制贴在对应判断后，并导出一个具体问题。

可用段落骨架：“在〔可比体系/条件〕下，现有证据支持〔具体判断〕。采用〔测量/比较〕的研究报告〔实际方向与范围〕，而〔另一条件〕下的结果为〔实际相反或不确定结果〕。这一差异与〔已有证据的条件差异〕一致；目前仍不能区分〔两个解释〕。因此，〔证据支持的意义或下一问题〕。”所有括号均由实际证据替换，缺失数值可省略，不生成示例结果冒充实测。

避免“甲发现、乙发现、丙也发现”的串列。把相关研究合并为有证据支撑的主题句；不显著研究也进入比较，不以显著论文计票，也不把多篇同队列报告称为独立复现。

## 将缺口转成问题

区分未覆盖的对象/条件、缺少独立重复、方法不可比、关键连接未测与结果真正冲突。只对实际检索和读取范围描述“尚未找到”；“首次”“无人研究”须有足够证据，不能由零命中推得。

把“应开展更多研究”改成“哪个因素在何种条件下解释哪项差异，什么比较/测量能够区分解释”。不为每个主题堆一套组学、动物、机制和工业试验；限定结论可完成现有证据的综述任务。

## 成稿复核与衔接

写完用户要求的正文后，按[领域写作](domain-writing.md)选择相关方向，把endpoint转成准确可用的句子；再按[专业润色](polishing.md)检查贡献主线、去防御与自然表达。只要纲要时检查逻辑、证据和问题，不扩写正文。

核对主张与引文、摘要与正文、模型/单位/n、图表与效应方向、相反证据和实际访问范围。将剩余证据问题单列在稿件后，不让重复免责声明淹没已支持的主要判断。其他章节成稿可交给[科研写作](writing.md)，复用原证据表。
