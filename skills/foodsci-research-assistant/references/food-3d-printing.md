# 食品 3D 打印：实验设计、分析与审稿修订

用于挤出式食品打印的配方、可挤出性、保形和加工后表现研究；其他打印技术须另核对方法。无专用数值脚本；本文件不提供通用打印参数或证明食品安全的 SOP。

## 研究目标与必要输入

- 先区分“配方能否挤出”“几何成形是否准确”“加工/贮藏后能否保持形状”“质构、感官或营养目标”。选主要终点和比较对象，不能把这些目标合并为一个无定义的“打印效果”。
- 提供原料来源与批次、干湿基配方及加水量、粒径/分散、混合与热历史、静置/储存时间、实际打印温度；声明配方是否改变了固形物或蛋白等营养组成。
- 提供打印设备、挤出驱动方式、料筒/喷嘴几何、层高、路径/填充、移动速度、进料量或压力及控制模式、CAD/切片版本、环境与后处理。只填实际测量或设定值，缺项标待补。
- 说明流变仪几何与间隙、温度、预处理/静置、剪切或振荡程序、壁滑/蒸发等检查。屈服应力、黏度及恢复率依测量定义解释；单个文献的可打印区间不能当通用阈值。

## 设计与对照选择

| 研究问题 | 适用比较 | 主要取舍 |
|---|---|---|
| 配方改善打印 | 基础配方或适用参考墨水；按目标匹配固形物、水分或蛋白投入 | 同质量与同营养组成回答不同问题；不能把加水差异归为单一组分作用 |
| 打印参数作用 | 固定墨水与设计，按计划操纵喷嘴、进料或路径等 | 配方与参数可交互；设备达不到的组合先说明可行性，失败不静默删除 |
| 打印过程改变质构/功能 | 相同配方的成型/挤出或适用未打印对照，尽量匹配热史与储存 | 若路径、热处理和配方同时改变，只能解释该组合工艺的效果 |
| 营养、消化或特殊人群用途 | 同配方/投料基准并接入对应功能与模型评价 | 外形、流变和质构数据不自动证明吸收、吞咽适用性或人体功效 |

- 配方是总和受约束的混合因素；适用时使用混料或因素设计，先明确主效应、交互和主要比较，再决定试验量。
- 记录独立配料批次、打印运行、同运行中的多个打印件，以及一件上的测量点。独立单位取决于处理在哪一级独立分配：同一配料/运行打印多件不能自动增加配方层面的 n。
- 跨日、喷嘴/设备与运行顺序随机化或区组；把料筒内停留、堵塞、换料和运行漂移纳入记录。不要把一次运行中的时间顺序当独立重复。
- 样本量围绕主要终点、真正独立批次和预期变异规划，不固定“三次即足够”。打印失败率须给尝试总数、预定失败定义及排除理由。

## 测量定义与分析

1. **几何保形**：预先选择线宽/高度偏差、轮廓面积差、体积差、悬垂或塌陷等指标，并记录相对于 CAD 还是打印后初值、正负号/绝对值、分母和测量时间。面积相近不证明三维形状一致。
2. **图像测量**：保存原图、尺度、视角/光照、分割与配准规则、软件版本及人工修正；不能通过逐件拉伸或归一化尺寸消除真实误差。必要时盲法复测或用适当实物测量核查。
3. **加工与贮藏**：分别报告打印后、加热/冷却后及规定储存条件下的尺寸与质构；重量、水分变化可能解释收缩，不能直接归因于“结构更稳定”。
4. **流变关联**：给出同批墨水与打印终点的配对关系；相关或模型拟合不等于因果。预测模型按独立配料/运行划分训练与验证，避免同批多件泄漏到两侧。
5. **层级与多终点**：在批次/运行内汇总或用适合层级的模型；重复时间测量保留相关结构。报告效应、区间、失败及真实独立 n；不从示例照片补造显著性。

最低数据记录：配方/原料批次、运行和打印件编号、处理分配、CAD/切片版本、参数、开始/结束时间、实际环境/样品温度、失败记录、图像/流变/质构原始文件与分析规则。

## 审稿修订：按主张提出最小要求

| 稿件主张或问题 | 最小可验收证据/修改 | 证据不足时的结论路径 |
|---|---|---|
| “提高打印保真度”，只给挑选照片 | 明确指标、测量时间、所有尝试及运行层级；重析已有可比原图 | 改为本条件下的成形可行性展示，不声称普遍改善 |
| “流变决定打印性”，参数与配方同时变化 | 报告混杂，提供可分辨比较或适用独立验证 | 改为该配方与设备组合的关联，不宣称通用阈值 |
| 同一运行多个打印件被写为独立 n | 依据分配层级重报 n 与分析；解释能支持的范围 | 保留运行内描述，独立运行不足的推断标探索性 |
| “适合食用/保健/工业生产”仅凭可打印 | 对相应主张提供食安、功能或放大资料，分开评价 | 限为材料与成形性能，不要求无关动物实验来保留这一有限主张 |

问题严重度取决于其对核心结论的影响。未提供参数先列信息缺口；只有发现可定位矛盾或足以改变推断的错误，才写成确认问题。复审检查修订正文、图表和 n 是否真正一致。
