# 数据分析与证据图表

先读[可复现分析](analysis-workflow.md)，需要作图或图注时读[证据图表](figure-evidence.md)。从真实输入、数据字典和实验记录确定分析目标与方法；不把写出代码视为已执行。

核对来源、单位、比较方向、独立实验层级、配对/重复测量、批次、校准、缺失和排除规则。按设计选择描述或推断方法，报告效应和适当不确定性，保留异常与相反结果，不为显著性更换单位、删点或挑模型。组学/预测任务检查训练与验证隔离、折内处理及多重检验；富集、相关和特征重要性各自按其推断范围解释。

实际执行时保存本任务代码、输入哈希、软件环境、逐独立单位汇总、计算结果和必要诊断。可用方法与依赖以本次环境为准，未执行的模型或图导出明确标为计划。少批次、重复验证或混合结构的不确定性应按真实独立单位处理，不把仪器重复或交叉验证折数当新增生物样本。

随包固定程序的范围见[数据契约](data-contract.md)：`scripts/analyze.py` 只做约定 RAW/消化的描述汇总。其他任务可在宿主实际具备工具时另写并运行适用代码，不新增“通用统计引擎”承诺。无原始数据时仍可交付字段、模型选择依据和待运行方案。

需要重新设计取样与对照时衔接[实验设计](experimental-design.md)。用户要求结果、图注或讨论成稿时将同一数据/比较/图 ID 交给[科研写作](writing.md)与[专业润色](polishing.md)；润色不得升级统计或机制结论。
