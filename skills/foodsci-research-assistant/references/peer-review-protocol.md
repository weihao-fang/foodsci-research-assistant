# 专业审稿协议

## 审查基础与五个角度

先固定本轮材料版本和覆盖范围；无完整材料时完成可核查的部分。按用户要求确定输出语言、深度和领域，不用完整审稿拖慢一段摘要的检查。

| 角度 | 核心问题 | 不应替代的证据 |
| --- | --- | --- |
| 食品科学贡献 | 研究对象与真实食品/成分/加工问题的联系是什么，新增知识相对哪些已查文献成立 | 不以“首次提取某植物多糖”或高影响期刊措辞代替创新对照 |
| 方法与测量 | 材料身份、基准、加工处理、对照、校准和干扰能否支撑所测终点 | 不能把方法名、商品试剂盒或一个谱峰当成适用性已经证明 |
| 设计与统计 | 实验单位、分层重复、配对/区组、模型和不确定性是否匹配推断 | 不把技术孔数当n，不从摘要数字补算未提供的P值 |
| 证据与解释 | 替代解释有没有被实际排除，结论是否超出所测对象/模型/时间范围 | 化学、体外消化、细胞、动物及人体证据不能直接互换 |
| 读者与呈现 | 论文是否清楚传达贡献，并符合真正核验的目标期刊范围和报告要求 | 适刊、有效性和语言质量分别判断；不能当作接收决定 |

## 主张—证据台账

只对本轮关键主张建立简短记录：主张ID、原意和稿件位置、所需证据、实际见到的证据与位置、支持范围、未评估事项。首先检查摘要—方法—结果—图表—讨论在剂量、单位、重复数、组别及统计叙述上是否一致。

证据定位按实际类型记录：正文段落/原句、表的行列、图中实际可见面板、公式编号及变量、数据文件与列/记录ID。报告“缺失”时说明原应出现什么、查阅过哪些部分及缺口如何影响解释；未提供的材料列“未评估”。不编造页码、图像特征、数据行或外部文献。

如果主张只能由摘要线索或作者描述支持，就保留这个范围。书目元数据一致不等于已读全文；已读某方法论文也不等于用户确实按它操作。对外部背景、期刊政策、标准或法规要求保留来源、日期及实际获取范围；无法访问的来源只作待核验线索。

## 每个问题的最小闭环

1. ID与适用角度，定位作者主张和证据。
2. 观察事实及其状态：已确认问题、需澄清疑点或材料不足未评估。
3. 该事实为何改变结论、估计或可复现性；说明合理替代解释，而不把它冒充为已证实原因。
4. Major/Minor及Blocking判定，明确阻断的主张；疑点没有足够证据时先列澄清，不当作已证实严重缺陷。
5. 最小必要修复与可验收关闭标准。可行时同时给缩小主张的路径；理想的新增研究另列可选增强。

不要重复计算同一根本问题来放大严重性。保留支持性证据、作者限定和真实优点；它们不能用分数抵消有效性缺陷，也不能因为预期“严厉”而省略。

## 统计与图表的审查界限

- 明确食品批次、独立提取/加工/消化/培养运行、板、同一样品读数和感官受试者等层级。日期或新孔号不会自动构成独立单位；多个终点也不是新增样本。
- 对批次内拆分、同一对象重复测量、时间序列和嵌套样品检查配对/相关性。按设计判断模型，不机械要求一种检验。技术重复先汇总不代表可以忽略所有其他层级。
- 核对n、SD/SEM/CI、检验对象、效应量和多重比较与稿件描述是否相容。小n意味着估计可能不精确，不等于自动无效；是否需要更多独立单位须联系目标效应、变异、精度和主张范围。
- P值未达预设阈值不能写显著，也不证明无效；只有摘要均值和误差不能验证原统计。误差条是否重叠不能单独判定显著性，不能仅凭图形判定造假。
- 只在确实取得适当原始数据、设计和工具并实际复算时说已复算。任何排除、变换、归一化、标准曲线和拟合都需可追溯；未提供并不自动证明作者违规。

## 多视角深审的执行诚实

默认先做单份综合预审。若用户要求多审稿人，或确需独立复核且有隔离上下文能力，可安排与材料规模相称的审查调用。记录实际调用数、材料版本及角度，不编造姓名、机构或人类专业资历。

分发包只含同版本稿件/资料、共同标准和该调用预定角度。不得含其他审稿意见、主持人猜测或引导结论。报告完成后先冻结，汇总只合并有来源的发现并映射原ID，保留相反判断及其证据。不能在汇总时凭空新增批评，不能为减少重叠修改原报告；真正的新问题需另行查证并标明来源。

若要使用“两个审查者共同指出”，必须确有两次隔离报告独立提出同一根本问题；同一代理换标题/语气不算。共识也不是正确性的证明，相同模型与资料的局限仍存在。

## 修订复审

先记录原ID、影响、原关闭标准、目标期刊及已约定范围。先比较原稿与修稿证据，再读对应作者回复，避免把说服性文字当成完成证据。若一份输入同时混有回复与修订稿，不能声称过程真正互盲，但仍应逐项查原始锚点。

逐ID写状态、修稿定位、实际改变、剩余影响及下一项可验收动作：

- 已解决：原缺口有修订稿/数据/限定结论支撑，或有证据的反驳消除原疑虑。
- 部分解决：已改变但仍未达到原关闭目标。
- 未解决：实际证据未改变，只有承诺或回复声明。
- 变差：修改引入新的不一致或扩大不支持的主张。
- 无法核实：缺修稿、数据或足够版本定位，不以回复代替验证。

接受达到同一目的的等效修复，不要求逐字照做。新问题注明“修订引入”“原稿已有但首轮漏审”或“无法归因”；新的真实有效性/伦理风险仍需报告，但不能偷偷改动原标准。换期刊时单独更新适配审查，不倒改原刊的复审结论。

## 最后核对

每条Major都有真实定位、证据状态、影响和关闭标准；Blocking只对应中心主张。未评估项未冒充缺陷，优点与反例没有被删除。没有虚构文献、独立专家、复算、当前政策或期刊决定。报告不直接修改原稿，所建议的必要证据与可选增强分开。
