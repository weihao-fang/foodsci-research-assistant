# RAW264.7：实验设计与数据分析

先读取 [数据契约](data-contract.md)；解释活力、Griess 读数或机制时读取 [终点与结论边界](raw2647-interpretation.md)。RAW264.7 为小鼠来源细胞模型，实验结果只能支持相应条件与终点的结论。

## 实验设计：数据采集前

先明确研究问题是处理对某个可测终点的影响、基质干扰，还是需要额外干预支持的机制问题。按主 Skill 形成因素/对照表、独立单位与重复依据、随机化/区组及主要终点的预定分析；不把所有检测都列为同等主要终点。

按实际问题规划未刺激/溶剂细胞对照、刺激模型对照、样品处理、无细胞试剂空白与含样品无细胞基质对照；阳性对照需有适用依据。将活力/损伤与炎症读数的条件对应起来，预先安排检测范围和干扰验证。样品浓度、刺激条件、处理时序、传代适用性及终点由实际方法与预实验支持，不能直接补为“常用”参数。独立培养/实验运行与复孔分开登记；用实验日/板的区组和布局控制操作差异，保留运行内处理—对照对应。样本量按主要比较的变异与目标精度/功效规划，增加复孔不会自动增加独立 n。

## 已有数据分析：确定分析单位与对照

取得原始板图、原始读数及实际方法记录。确认细胞来源/鉴定和污染检测记录、传代信息、刺激与处理时间、浓度及单位、溶剂对照、检测方法、批次和板号；未提供就记录缺失，不能补为常用条件。

明确独立细胞培养/实验运行与同一运行中的复孔。`experiment_id` 必须对应研究者可解释的独立实验单位；同一培养物的多个孔、多个检测值或多个板不因编号不同而成为独立生物学重复。保留同一次运行的处理与对照配对关系。

区分无细胞试剂空白、含样品的无细胞基质对照、未刺激/溶剂细胞对照、LPS 模型对照及阳性对照。它们回答的问题不同。确认食品颜色、浑浊或还原性是否影响检测；没有检测依据时标记“干扰未排除”。未知空白不能写成 `0`，不得重复扣除已校正数据，也不能在不匹配的板、浓度或处理条件间借用空白。

## 描述性分析

只有当前宿主有Skill 文件访问权和 Python 执行能力时，才从Skill 根目录运行；其他情况下给用户本地命令并明确尚未执行。

```text
python scripts/analyze.py raw --input data.csv --output new-raw-result.json --reference-group LPS
```

CSV 必须包含 `experiment_id,plate_id,well,group,endpoint,value,blank,unit`。本工具扣空白，在同一实验/板/终点/组内汇总复孔，以同板同实验同终点的指定参考组归一化；随后等权汇总实验内各板，再跨实验给均值和样本 SD。它不做标准曲线、单位转换、细胞毒性判定、抗炎判定或推断统计。

`--reference-group LPS` 只是示例，必须依终点选择真实存在且科学问题匹配的参考组。活力通常需要声明的未处理/溶剂细胞参考；炎症终点可能参考 LPS。不同终点需要不同参考组时，按终点分文件运行并保留来源映射。不能把相对 LPS 的信号自动改称“存活率”。参考校正值非正时不计算比例。

逐项检查单位、重复孔键、非有限值、极端/负的校正读数、板间偏移及缺失对照；不截断负数，不按期望结果删异常孔，不把缺失值补成零。原始值与校正值都要可追溯。报告各独立实验的值和技术孔数；SD 描述实验级结果的离散程度，不以全部孔数当作独立 n；n=1 时 SD 不可估计。

解释 Griess、活力、细胞因子、qPCR 或免疫印迹前，核对对应方法与分母。活力与炎症终点应在可比较的处理条件下共同审查，但不能无验证地将炎症信号除以 MTT/CCK-8 百分比。若炎症相关读数下降同时存在细胞损伤或干扰疑点，列出替代解释，不作确定的抗炎结论。qPCR 的 ΔΔCt、免疫印迹的内参及 ELISA 的浓度换算需另行核验；本 CSV 工具不实现这些方法。

## 交付结果

输出审计问题、实验级数据及描述性汇总，列明输入文件/工作表/行、分组键、空白来源、参考组、排除原因和实际使用的计算步骤。实际运行时记录命令、输入哈希（可获得时）和产物路径。区分“未提供”“未检测”“检测合格”，不能互相替代。

仅凭汇总图、均值±误差条或缺乏独立重复的数据，不编造 p 值、置信区间、显著性星号或新的独立重复。若请求推断统计，先取得实验级原始数据、独立性/配对结构、计划比较与多重检验方案；由适合的统计方法另行分析并记录，不能暗示本工具已完成。

中英文结果只填写真实指标、单位、参考组及 n。无检验时可写“该条件下读数较低（描述性比较）”/“The measured signal was lower under the tested conditions (descriptive comparison).” 不直接写人体健康功效。NF-κB、MAPK 等表达/磷酸化变化可描述为关联；单凭这些变化或单一抑制剂结果不足以宣布通路因果机制。机制主张需评估干预特异性、独立证据与替代解释。
