# SYNTHETIC｜燕麦发酵凝胶下一轮试验单

**状态：虚构情境下的拟开展方案；没有实验数据或优选结果。** 本轮以固定原料批号筛选配方与加热条件，不声称寻找全局最优。主要终点为冷藏第14天自然离水质量百分比，硬度0.8–1.8 N作为筛选门槛；pH、滴定酸度和活菌数解释发酵表现。

## 1. 处理与用料

每份均独立称料、混匀，最终300.00 g。所有份均为粉料24.00 g、油6.00 g、糖9.00 g、盐0.30 g、发酵剂或其原位受热灭活物3.00 g；常规总水量257.70 g。酸化对照的乳酸液按质量替代部分配方水，最终仍为300.00 g，不能在300 g之外追加。

|配方ID|燕麦:豌豆蛋白:菊粉（粉料质量%）|每份三种粉料（g）|本轮用途|
|---|---|---|---|
|F0|70:25:5|16.80 / 6.00 / 1.20|现配方参照|
|F1|60:35:5|14.40 / 8.40 / 1.20|以蛋白替代部分燕麦|
|F2|60:25:15|14.40 / 6.00 / 3.60|以菊粉替代部分燕麦；预选机制比较配方|
|F3|55:30:15|13.20 / 7.20 / 3.60|联合改变的筛选点|

每轮固定6份：**L0、L1、L2、L3、A0、A2**。L为对应F配方的活菌发酵；A为对应配方的非活菌、乳酸酸化比较。F2在采集数据前指定，不能看结果后换成“最好配方”。F1、F3若表现好，本轮仍没有它们各自的酸化对照。

本轮操作约定为**在同一规格300 g制备容器内完成16 h发酵/酸化，终点同样轻混、分杯冷藏**，便于实施酸化轨迹比较；结论仅适用于这条工艺。如果现产品在杯中静置成胶，本轮不能当作该静置工艺的直接确认。

## 3. 一轮怎么做

1. 每份均预留6.00 g配方水作37°C阶段加液预算，先用251.70 g水制基料；L的3 g发酵剂待冷却后加入。A的同量发酵剂在本次加热前加入，使其随基料受热，既不省去发酵剂载体，也不增加水浴轮次或位置。A因此是“预加发酵剂受热＋乳酸酸化”对照，须用计数检验其非活菌状态。
2. 同型容器、装料、搅拌方式和探头深度。记录每份中心达温、保温起止、冷却轨迹；各份中心达目标温度后保持10 min。称重，只补回蒸发水至该份加热前质量，不能补入因取样损失的质量。冷至37°C后L加发酵剂；各份以达到37°C、完成加样为各自0 h，37°C保持16 h。两轮起止时钟分开记录，不强迫同时入冷藏。
3. 在0、2、4、6、8、10、12、14、16 h测pH，原位读取避免反复耗样。0 h不强行拉平配方原有pH。2–16 h在同温条件下，以当时L0、L2的pH分别作为A0、A2目标，食品乳酸缓慢分次加入、统一轻混后复测，不作一次性骤酸化；记录酸液批号、标示浓度、每次质量、加前/后pH。每个节点先确定两A组所需酸液质量，取两者较大者m：所有L加m g水，A加各自酸液并以水补到m g，使6份该节点总加液质量一致。逐步少量试加并复测；酸化过头不能用碱倒调。全程累计共同加液不得超过6.00 g；16 h各份以剩余预留水补齐预算。超预算或无法匹配则标记酸化比较失败，不挤占其他份数、不暗改配方。
4. 16 h记录pH、滴定酸度及活菌数，轻混、分杯。原位pH测量应使用清洁消毒并充分去除残留的探头，组间避免交叉污染；终点余料用于酸度/计数。所有化学酸化和轻混、假加水操作均记时，L/A采用同样操作频次。以转入4°C为冷藏计时起点；S00在核心冷却到4±1°C后的统一窗口检测并记录时长，S07、S14分别在冷藏起点后7、14天同一允许窗口（±2 h）取杯。记录实测冷藏温度，拆开的杯不回库。

乳酸用量、目标pH和酸度均由实际轨迹决定，本方案没有虚构这些数值。6 g预留量是本轮操作上限，未证明足够；不足只降低机制比较的可解释性，不补造匹配。

## 4. 最有判别力的比较及边界

同一生产日、同一温度下，比较**L2对A2**，同时用**L0对A0**检验现配方的背景；可再看两种配方的L−A差异是否不同。这比“发酵样对未接种样”或只在终点调同pH更接近问题本身：相同配方与热处理、相近酸化过程下，乳酸能否重现其离水与硬度表现。

预先规定可解释性门槛（本轮建议值，非已验证标准）：过程对应时点pH偏差尽量≤0.10；16 h及所比较的冷藏时点pH差≤0.05，滴定酸度相差≤10%（同一方法、以L为分母）。A的可培养乳酸菌须低于已记录方法检出限，不能把未检出写成绝对无菌。保存原始偏差，不为达门槛删掉样品。冷藏中不再开杯补酸；若S14酸度/pH已经分离，S14的品质差异仍可能由后酸化造成，不能排除酸化解释。

满足匹配而L与A仍有稳定差异，最多支持“本条件下，所模拟的单纯乳酸酸化不足以重现活菌处理”。**不能据此认定特定代谢物、胞外多糖或活菌本身是原因**：A中发酵剂受热时机不同，酸种、离子强度、细胞状态和底物转化仍可能不同。若两者相近，只能说酸化可重现所测表现；没有等效界值和精度依据，不能宣称机制完全相同。特定物质归因留给后续同基质分离/去除与补回试验，不占本轮48份。

## 5. 读数如何汇总

每时点两杯均保留独立杯号：先称净样质量，未扰动时轻吸取全部可见游离液并称重，定义自然离水率`100×游离液质量/开杯时净样质量`，不离心、不压挤；再在完整胶体两个不重叠位置各压1次。硬度沿用产生0.8–1.8 N门槛的同一探头、速度、形变和温度SOP并记录参数；若原门槛对应其他测法，不能直接套用。压测探头按无菌取样要求处理，随后从未接触探头区域取菌数样，剩余样测pH、滴定酸度；游离液分布须在微生物取样记录中注明，菌数取样应覆盖规定的代表性胶体/液相，所有组一致。若现有硬度或离水SOP要求整杯破坏，则本方案的联合测定不可直接沿用，须在开做前锁定这套不挤压的自然离水定义与杯内测点，不能临场增加杯子。

- 同杯2次压测先平均；再将两杯各指标汇成该份该时点一个值，同时保留杯间差异。两杯不物理混池，不能冒充两个独立300 g制备。
- 双平板是同一稀释液的技术重复；先按锁定的计数范围、稀释倍数与涂布体积算每杯CFU/g，再换算log10 CFU/g并汇总两杯。多个稀释度不是多个n。记录原始菌落数、检出/定量限；低于限值保留为删失值，不记零或任意加1。该方法若不能鉴别发酵剂菌株，就报告可培养目标菌数而非菌株特异存活。
- pH校准、滴定空白与终点、计数方法及质构SOP在D1前锁定；酸度统一报乳酸当量g/100 g并注明只是当量。保温失败、漏杯、污染、超预算及读数越界均保留原因和原值，缺失不当作零，不因离水偏高排除。

## 6. 预定分析与筛选决定

**先描述，再作有限比较，不进行无数据的检验。** 配方主要比较仅用32份L。各温度内，将F1–F3与同日同温F0比较S14离水率的差（百分点）及硬度；画4个生产日配对差值。每个配方×温度有4份独立制备，每份的3个冷藏时点来自不同杯，却共享同一制备历史，必须保留批次相关性。

温度是在整轮分配：共8个整区、每温度4轮；温度效应先看每天两个温度的轮均差，不能拿每轮6份、杯或压测当作温度运行重复。顺序已平衡，但仍记录轮次、实际温度和起止时刻。配方是轮内因素，生产日是区组；比较冷藏时间及配方×时间、温度×时间时保留同一制备的相关性。必要的探索模型可用生产日区组、日内温度运行误差层、制备层与时间分类效应；小样本或模型不稳定时只报分层均值、配对差和范围，不靠忽略层级换取显著性。

配方首先作为4水平类别，不能把三个受总和约束的粉料当作三个可独立增减的普通因素。若探索连续混料趋势，至多用不带截距的一阶混料项及其温度交互；4个混料点不足以估计完整6项二次混料曲面，不能输出未实测“最优点”或宣称已识别曲率。A组另作预定L0−A0、L2−A2配对描述，不混入活菌配方筛选拟合。

建议在揭盲前冻结的筛选规则：候选配方×温度在S00、S07、S14的4个制备均值均落入0.8–1.8 N；S14相对同温F0的平均离水降低至少**2.0个百分点**，且至少3/4个生产日方向一致。2.0个百分点是待团队接受的实际改善阈值，不是已知变异、功效或行业标准。没有方差依据，4日由资源上限决定，不能承诺检出能力；本轮用于获得日间及运行间变异，供后续独立确认规划。活菌/酸度报告轨迹和异常，不凭空设未提供的合格菌数线。

通过者仅称“本轮值得独立批次确认的候选”；未通过则报告未找到满足本轮规则的候选，不挑一个硬度不合格者补位。所有48份均用于筛选/比较，尚没有独立确认批次，也没有获得安全货架期、上市或消费者接受性证据。方法依据限于本次任务及包内实验设计、Scientific方法选择、发酵、贮藏与交叉桥接指导；本次没有联网核验或实际实验。
