# 安装后，花三分钟试一次

先在[下载页](DOWNLOADS.md)选择包，按 [Codex 安装](INSTALL_CODEX.md)或[豆包使用](INSTALL_DOUBAO.md)完成适合当前环境的准备。这里的三分钟用于体验一个小任务，不是所有客户端安装耗时的承诺。

## 1. 明确使用 FoodSci

在新对话中选择已安装的 `foodsci-research-assistant` 总入口，或按宿主支持的方式明确调用 FoodSci。五个任务入口分别用于文献与综述、研究与实验设计、数据分析、写作与润色、审稿与投稿；只用总入口也能读取内部模块。

不要仅凭模型回复“已使用”判断已安装。按安装教程检查实际入口和资源；豆包按其说明使用，不视为已经原生安装 Codex Skill。

## 2. 选一个小任务

初次试用可先拿[简短润色原稿](../examples/polishing-quickstart/input.md)，交付可与[本次中英文定稿](../examples/polishing-quickstart/output.md)对照；也可在[首页三个例子](../README.md#先看三个使用例子)中选实验设计或数据分析。均为合成或虚构演示，当前Skill版本为0.8.1。

0.8.0另提供两份实际执行的SYNTHETIC新例子：[配方与工艺任务](../examples/formulation-design/input.md)→[可执行设计](../examples/formulation-design/output.md)；[原始读数任务](../examples/processing-analysis/task-b-analysis.md)→[计算与英文Results](../examples/processing-analysis/output.md)。后者附固定教学数据的实际代码和结果，可在自己的新输出目录复算，不是新增通用分析器。

优先试用公开资料、最小脱敏段落或明确标记的合成样例。下列三条任选其一。

**综述：**附上[合成资料输入](../examples/literature-review/input.md)，复制：

> 请使用 FoodSci，只依据我提供的 SYNTHETIC 摘录，写一份限定叙述性综述。交付简短两级提纲、500—700 字正文和报告—研究—证据表；保留阴性结果、仅摘要可得的范围及同研究多报告关系，不另检索，不合并总效应。

**润色：**附上[合成双语原稿与锁定记录](../examples/bilingual-polishing/input.md)，复制：

> 请使用 FoodSci 润色这份合成中英文结果段，依据锁定记录纠正事实冲突，直接交付两种语言定稿。先给主要判断，再给证据；保留数字、单位、独立 n、CI、P、阴性结果及关联或推测程度，不生成新统计或新文献。

**自己的资料：**提供一篇公开论文、一个脱敏段落或一张说明清楚的表格，复制：

> 请使用 FoodSci。我的问题是【问题】，已有材料是【文件及其含义】，这次只需要【证据表/实验方案/分析/正文/审稿问题】。请完成这个范围；实际没有读取或执行的部分明确标注，只追问会影响方法或结论的关键缺失信息。

## 3. 检查交付是否可继续使用

| 检查什么 | 怎样判断 |
| --- | --- |
| 来源 | 引用和判断能定位到提供的材料，未读取全文不会写成已核验 |
| 样本 | 技术孔、图像视野和重复导出没有增加独立 n |
| 数字与含义 | 单位、方向、CI、P、阴性结果及关联/推测程度保留 |
| 执行状态 | 计划、待运行代码和已实际运行的结果区分清楚 |
| 交付范围 | 得到本次要求的可修改产物，没有被无关流程替代 |

可与[综述历史输出](../examples/literature-review/output.md)或[双语历史输出](../examples/bilingual-polishing/output.md)比较结构和事实保留方式，不要求逐字一致。这些是已有 0.6.0 合成演示，不代表本次 0.8.0 新行为验证，也不是科研结论。

## 想继续试分析或研究设计

离线数值样例见[RAW/消化演示](demos/offline-analysis.md)，需要 Python 3.10+。其他数据可先提供列字典、独立批次和配对关系；宿主缺少软件或执行能力时应交付计划，不应产生声称已计算的数值。

研究设计可以问：“围绕我的主张列出竞争解释，选择最小判别试验，明确对照、独立单位、取样终点和分析计划，不默认增加全套组学或动物实验。”完整能力与材料要求见[功能说明](FEATURES.md)。

发现问题时按[反馈格式](../CONTRIBUTING.md)提供版本、宿主和最小脱敏复现，不公开保密稿件或个人信息。[返回首页](../README.md)
