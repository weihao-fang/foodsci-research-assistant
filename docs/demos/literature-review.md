# 演示：六份资料怎样写成有判断的综述

**来源：已有 0.6.0 合成任务。所有报告、标识与数字均为 SYNTHETIC 软件测试资料，不可作为科研证据引用。本页展示的是既有执行结果的校订版，不是本次 0.7.0 新前向行为验证。**

## 输入与任务

主题是“发酵豌豆蛋白小分子组分：加工表征、消化稳定性与免疫相关效应”。输入提供 R1—R6 六份报告摘录，涉及加工表征、模拟消化、RAW264.7、Caco-2 及小鼠；要求只用这些材料完成限定叙述性综述，不另检索。

其中 R2 沿用 R1 同批次、同一细胞实验的留存材料，新增的是 IL-6 mRNA 检测；R4 仅摘要可得，缺少剂量、时点、独立 n 和完整方法。两处信息决定了哪些证据能合并理解、哪些判断需要保留范围。

## 实际交付中可以观察什么

| 输入中的难点 | 输出中的处理 |
| --- | --- |
| 六份报告容易被误算成六项独立研究 | 映射为五项研究，R1/R2 同属 S1，补充终点不作为独立复现 |
| 有阳性、阴性和不确定结果 | 同时保留 NO、IL-6 mRNA 与未发酵酶解组的比较，没有按显著性投票 |
| 模型与制备路径不同 | 按科学问题比较，不把不同体系数字合成总效应 |
| 摘要缺少关键信息 | 标记摘要层级及缺失项目，不把用户摘录称为已读取原始全文 |
| 容易从组分一路写到人体机制 | 区分加工表征、消化后组分、细胞及动物终点，保留未测连接 |

实际产物包括标题、两级提纲、正文与“报告—研究—证据”表。正文提出可继续检验的问题：统一实验室与原料、匹配组分范围及剂量后，发酵与酶解组分的 NO 差异能否重现，并在模拟消化后保留？

这里的价值是把资料组织成可定位的判断和下一步问题。它没有完成真实文献检索、原始全文核验、系统综述或元分析。

## 怎样复用

将完整输入交给 FoodSci，明确保留 SYNTHETIC 标记，要求同样的交付。对照时检查研究映射、阴性结果和证据范围；无需要求文字逐字复现。换成自己的资料时，附来源和真实读取范围，不沿用本演示中的虚构文献标识。
