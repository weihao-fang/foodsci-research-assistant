# 演示：纠正事实冲突，同时交出可用双语正文

**来源：已有 0.6.0 合成润色任务及修复后的独立复测。所有记录和数字均为 SYNTHETIC 软件测试资料，不是真实科研结果，也不是本次 0.7.0 新行为验证。**

## 输入与任务

用户提供中英结果前稿和锁定记录，要求直接交付两种语言定稿，不启动新统计或文献检索。记录说明处理物是燕麦 β-葡聚糖发酵上清冻干粉，三个独立发酵批次、每批三个技术孔；NO 比较为 −8.0 个百分点，95% CI [−17.5, 1.5]，P=0.08。

前稿同时含事实冲突和空泛表达。输出需要根据已有记录直接纠正错误，保留真实的不确定性，而不是把语言写顺后留下错误含义。

## 原稿 → 实际定稿

| 原稿中的问题 | 实际处理 |
| --- | --- |
| “纯燕麦 β-葡聚糖” | 改为真实处理物“发酵上清冻干粉” |
| 终浓度 0.40 g/mL | 依据锁定记录纠正为 0.40 mg/mL |
| 三批 × 三孔写成 n=9 | 批内先取技术孔均值，以独立发酵批次为 n=3 |
| P=0.08 写成“显著降低” | 保留差值、CI 和 P，说明未达统计学显著性 |
| 未测通路却称通过 NF-κB 预防人体炎症 | 删除超出实测证据的机制与人体结论 |
| 描述性共同变化被写成已检验相关 | 保留描述性关联和 may 的推测程度，不补造相关检验 |
| 以反复自贬和空泛强调开头 | 首句先陈述主要比较，描述性关联另成一段 |

定稿的主要结果句为：

> 与受刺激对照相比，燕麦β-葡聚糖发酵上清冻干粉处理组RAW264.7细胞的NO归一化读数组间差值为−8.0个百分点（95% CI [−17.5, 1.5]，P=0.08），未达统计学显著性。

完整输出还保留 IL-6 阴性结果、活力读数、处理条件及未检测的通路、吸收与人体结局，中英文事实对应。

## 怎样复用

附上原稿和可靠的锁定事实，明确要双语定稿、只润色一段还是重组整节。现有记录足以纠正时可直接改；记录本身冲突且无法解决时，应列出真正影响事实的问题，不能为使叙事流畅而猜测。

历史初测曾出现结果首句仍以条件开头、单段中心过多的问题；本演示采用补强规则后对同一原始输入的独立复测输出。它说明这一限定任务中观察到的变化，不保证所有模型和任意长稿一次达到相同表现。[当前版验证范围](../VALIDATION.md)
