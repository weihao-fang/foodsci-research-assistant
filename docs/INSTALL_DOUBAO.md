# 在豆包中使用 FoodSci 0.7.0

普通聊天推荐使用自包含的文本版；豆包工作任务模式如提供技能导入入口，可按实际界面尝试技能单包。两条路线的能力与验收方式不同。

## 普通聊天：上传允许的格式，或粘贴全文

1. 下载 [foodsci-doubao-chat-0.7.0.zip](../downloads/foodsci-doubao-chat-0.7.0.zip) 并在自己的设备上解压；也可直接打开[FoodSci 豆包聊天版](../adapters/doubao/FoodSci-豆包聊天版.md)。
2. 查看当前豆包会话的附件界面。只有界面明确允许且能够读取该格式时，才上传文本文件；否则用文本编辑器打开聊天版文件，将正文完整粘贴到消息中。不要把普通聊天接收 ZIP 附件视为技能安装。
3. 在自己的消息中明确说明采用这些规范，再给出任务及材料。例如：

> 我明确要求你把我提供的 FoodSci 豆包聊天版规范用于本次任务。请先确认能读取的内容和任务路线，再处理以下材料。缺少的证据或执行能力请如实说明，不要假定已安装技能或运行过程序。我的任务是：……

4. 用一个短任务检查：三次独立培养、每次三个复孔，应如何定义实验单位；尚未提供原始数据时不能给出统计结果。确认理解后，再提交真实研究任务。

文本版包含总入口、检索综述、规划设计、数据分析、写作润色和审稿投稿六条路线，正文可独立使用。普通聊天不保证自动读取其他文件、跨聊天保留规范、执行本地 Python 或连接专业数据库；新聊天需要重新提供规范。仅上传资料而未明确要求采用其中的工作规范，不能假定平台已将其作为本次任务指引。

## 豆包工作：按实际技能入口条件尝试

官方[豆包工作任务功能须知](https://www.doubao.com/legal/DoubaoAgentModeNotice)第四节确认存在“技能・连接器・伙伴”入口，技能来源包括官方、企业管理员上传、个人自定义及设备本地已安装技能。它没有在本次可读取文本中给出个人 ZIP 导入规范、`SKILL.md` 解析要求、包大小限制或准确的本地安装路径。不要把其中的目录表述推定为 Codex 的目录。

如果你的账户和版本中有明确的自定义技能“上传”或“导入”入口：

1. 先查看页面允许的格式、目录结构及权限提示。只有界面明确接受相应 ZIP 技能包时，才尝试 [foodsci-codex-0.7.0.zip](../downloads/foodsci-codex-0.7.0.zip) 这个标准单技能结构包。
2. 该包提供一个 `foodsci-research-assistant` 技能目录，目录内有 `SKILL.md` 和完整资源。使用前以界面要求为准；本项目尚未验证豆包能识别它，文件名中的 `codex` 也不构成豆包兼容认证。
3. 检查导入状态、技能名称及资源是否可读取，并显式调用后完成上面的短任务。只有导入与调用均通过，才记录为该账户、该客户端版本上的可用结果。
4. 遇到格式不支持、没有入口或资源无法读取时，直接使用普通聊天文本版。六入口套件共享同级总包资源，不作为豆包首次导入的默认选择。

本教程没有声称豆包原生兼容本项目 ZIP；也没有要求用户在未确认的目录中放置文件。豆包普通版、工作版以及网页、桌面和手机端的功能可能不同，实际入口不能互相代替。扣子 Coze、TRAE、火山方舟 API 的技能或文件规则不作为这些入口的兼容证据。
