# 食品与生物研究，可以怎样用 FoodSci

FoodSci是生物、食品及交叉科研的统一入口。按研究目标、材料、数据和目标产物选择方法，连接问题、证据与交付；纯生物、纯食品和新的交叉方向都适用。

## 特色研究示例

以下展示食品与生物专长，不限定使用范围。目录外的实验、数据类型、模型或科研交付可以直接提出，无需先选择示例、登记方法或建立新的子Skill。

**食品结构与功能。** 处理蛋白/多糖改性、复合体系、流变、食品3D打印和模拟消化中的结构—性能关系。检查表征是否对应目标性质、配方因素是否受总量约束、加工与材料变化能否区分、消化终点是否真的支持后续功能解释；据此选择关键对照、测量和分析。

**发酵与生物响应。** 将菌株、底物、发酵批次、代谢变化与细胞/动物终点对应起来。分清基因或酶家族注释、代谢物候选鉴定、相对丰度和实测活性，设计能够区分酸度、组分与活菌效应的试验。菌群、转录组及代谢组按各自数据结构分析，纯生物主题保留自身研究情境。

**保鲜与过程工程。** 围绕温度、时间、包装、配方和工艺组织实验，处理同批产品多时间点、破坏性取样、嵌套与生产批次问题。以微生物、品质和真实应用终点解释结果，区分代理指标改善、实际货架期证据与放大后的过程表现。

## 六个任务入口

| 入口 | 专业交付 |
| --- | --- |
| 科研总入口 | 确定问题、证据缺口和本次工作，按需联动后续阶段 |
| 文献与综述 | 可追溯检索与筛选、研究—报告映射、分层证据综合、综述提纲或正文 |
| 研究与实验设计 | 论文实验拆解、竞争解释、判别试验、因素与对照、独立单位及分析计划 |
| 数据分析 | 数据审计、设计匹配的统计、效应与不确定性、科研图表及可复现代码和结果 |
| 写作与润色 | 从确认事实起草中英文正文，精修论证、术语与表达，保留数字及科学含义 |
| 审稿与投稿 | 主张—证据审查、方法与统计复核、逐问题修订、现行期刊要求及作者回复 |

这些入口共享一套资源，是常用任务导航。研究构思、基金/课题申请、方法排障、序列/成像分析、模型代码、学术报告及其他科研交付，按实际任务组合适用方法，不以表格是否列出为准。只安装总Skill即可使用完整指引；五个独立任务入口须与总Skill一起安装。

## 专业资源怎样进入研究

FoodOn/FoodData Central帮助统一食品身份、加工状态和计量基础；UniProt与dbCAN支持序列、蛋白及糖活性酶注释的核对；QIIME 2、MetaboLights和GNPS提供微生物/代谢研究的数据与方法参照；ZFIN/MGI支持动物基因和表型证据定位。按[资源手册](../skills/foodsci-research-assistant/references/food-bio-resources.md)选择查询、记录ID与版本，并把查询结果交接到实验验证。

这些资源提供知识与方法依据。FoodSci没有随包复制数据库，也没有自动获得外部软件、付费文献、API密钥或仪器权限。

## 写出判断，守住证据

写作先组织核心判断、比较和证据，再优化语言。删除假想反对意见、空泛强调与重复澄清；有意义的阴性结果、关联程度、模型范围和统计不确定性继续保留。默认直接交付可修改正文，不以篇幅、套话或无依据的机制填满文章。
